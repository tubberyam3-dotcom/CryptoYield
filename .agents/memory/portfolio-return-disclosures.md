---
name: Portfolio return disclosures
description: How to explain configured portfolio returns without inventing or overstating earnings.
---

Use the configured periodic interest rate, period length, and meter reduction for expected-return disclosures. Annual figures are simple annualized rates, not compounded guarantees; time-based projections stop at the investment term.

**Why:** The accrual model pays interest on principal rather than compounding it. Annualizing a short-term product must not imply it keeps paying after maturity. The user requested usable annual and daily figures rather than empty or misleading displays.

**How to apply:** Keep these disclosures consistent across user purchase reviews, portfolio listings and admin creation previews. A genuinely zero configured rate must remain zero; do not invent a positive rate to make a display look populated.

Admins enter the Interest Rate per Period directly as a percentage: `0.1` means `0.1%`, for both creating and editing portfolios.

**Why:** The user explicitly requested direct percentage input rather than requiring admins to calculate a decimal fraction.

**How to apply:** Preserve existing economic rates when opening and saving edits; conversion of form units must not multiply existing portfolio payouts.
