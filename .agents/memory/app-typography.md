---
name: App typography
description: User's app-wide font requirements.
---

Use Urbanist for headings and Inter for body text, financial figures, tables, and controls across the entire web app.

**Why:** The user explicitly requested this app-wide typography standard.

**How to apply:** Preserve this distinction in future screens and shared components. Financial figures remain Inter even when displayed as headings. Do not introduce alternative text fonts for identifiers or controls; icon fonts are separate.
