---
name: Mobile account controls
description: Required mobile access to XP codes and joint-account management.
---

XP code and joint-account options must be available on mobile.

**Why:** The user explicitly requested mobile access. Separate mobile and desktop settings views previously omitted these controls on phones.

**How to apply:** Keep account controls functional across both layouts. Direct shortcuts must select the right settings section, not simply open the general settings page. Check both layouts when adding account/security controls.
